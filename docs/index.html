LehcimGamesLehcim Noil
Les jeux gratuits de Lehcim Noil, portés de Windows 3.x vers le navigateur, avec leurs graphismes et leurs sons d'origine.

Agora

Jeu de stratégie à piles : prises, prisonniers et révolutions. Contre l'ordinateur.

Awélé

Le jeu de semailles africain, en mode normal ou tournoi. Contre l'ordinateur.

Colours-MIX

Course de globules et mélange de couleurs. 1 ou 2 joueurs.

KevGame

Le poisson chasse le ver dans la piscine. 1 ou 2 joueurs.

LabRaph

Labyrinthes, globules jaunes et serpents rouges. Meilleurs scores.

Morpion

Aligne 5 billes pour marquer des points. Contre l'ordinateur.

Stack

Oriente les billes qui tombent pour protéger la "chose". Meilleurs scores.

Ces jeux étaient à l'origine des programmes Windows 3.x (256 couleurs, 640x480) distribués sur http://lehcim.flashyland.com. Les versions originales sont conservées dans le dépôt GitHub. Les règles ont été reprises des aides d'origine ; le code a été réécrit en JavaScript.
