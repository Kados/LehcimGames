Bouton gauche : glisser (ou cliquer la pièce puis la case visée) pour un déplacement ou une prise. Bouton droit (ou bouton Prisonnier) : se constituer prisonnier. Flèches ← → : tourner autour du plateau, ↑ ↓ : se pencher.

Règles du jeu

But du jeu

Un joueur gagne quand son adversaire ne peut plus jouer, c'est-à-dire quand ce dernier n'a plus de pion ou que ses pions sont tous prisonniers.

Déroulement de la partie

Les blancs commencent. Chaque joueur à tour de rôle doit mouvoir un de ses pions. Dans une pile, seul le pion supérieur peut bouger. Il existe 3 variantes de déplacements : le déplacement simple, la prise, le prisonnier. Tous les déplacements se font d'une case sur une case adjacente.

Le déplacement simple : le pion choisi est déplacé sur une des cases vides adjacentes (il y en a au plus 8, mais parfois aucune !).

La prise : votre pion est plus haut ou à la même hauteur que l'adversaire. Vous pouvez prendre. Votre pion est alors placé sur les pièces adverses qui sont retournées et changent ainsi de couleur. La prise n'est jamais obligatoire.

Le prisonnier : votre pion est plus bas ou à la même hauteur que l'adversaire. Vous pouvez vous constituer prisonnier. Votre pion est alors glissé sans être retourné sous les pièces adverses.

Si vos prisonniers deviennent majoritaires dans une pile, les pièces adverses sont automatiquement prises et donc retournées. C'est la révolution !

Attention, si vous quittez une pile, vos prisonniers peuvent devenir majoritaires. Dans ce cas, vos propres pions, devenus minoritaires, sont retournés.

Mouvements interdits

Il est interdit de s'empiler sur ses propres pions, sauf dans le cas du pion isolé (pion qui ne touche qu'un seul pion de sa couleur). Tout pion isolé peut s'empiler sur le pion qu'il touche. Le seul moyen de faire une pile avec un pion non isolé est de prendre ou de se constituer prisonnier.

Remarque : un prisonnier ne peut jamais être pris par les pièces qui le contrôlent. Par ailleurs, il est impossible de le déplacer.

Comment jouer ?

En déplaçant la souris, tu sélectionnes une case qui apparaît en surbrillance. Si la pièce la plus haute sur cette case t'appartient, tu peux la jouer.

Pour un déplacement simple ou une prise, clique alors avec le bouton gauche de la souris (la case choisie devient blanche si le coup est possible), puis, en conservant le bouton appuyé, déplace la souris sur la case visée et relâche enfin le bouton. Ta pièce se déplace alors automatiquement si le coup est conforme aux règles. Tu peux aussi cliquer la pièce, puis cliquer la case visée.

Pour te constituer prisonnier, le processus est similaire à celui du déplacement mais avec le bouton droit cette fois (sur écran tactile : active d'abord le bouton Prisonnier).

Si besoin, tu peux tourner autour du plateau, voire te pencher par-dessus à l'aide des flèches (ou des boutons de la barre « Vue »).

Celui qui commence a les blancs. Le bouton « Nouvelle position » te permet d'imposer ta propre position initiale : un clic gauche pose une pièce blanche, un clic droit une pièce noire (cliquer sur une case occupée ajoute la pièce sur la pile). Quand 16 pièces sont mises, le jeu commence. Attention, si tu veux placer toi-même les pièces au départ, choisis celui qui commence avant de cliquer sur « Nouvelle position » !

Note du portage : une partie est déclarée nulle si la même position se répète trois fois ou après 400 coups.
